# 天空之城：第一人称世界

打开 `Assets/Boids/Scenes/SkyCityWorld.unity` 并进入 Play。编辑器中先点击 Game 画面。

| 操作 | 效果 |
| --- | --- |
| WASD + 鼠标 | 沿视线飞行、转向 |
| 滚轮 | 调整相机移动速度，2–36 m/s |
| Q / E、Shift | 下降 / 上升、加速 |
| 鼠标右键 | 在前方呼唤鸟群，盘旋后自然散开 |
| Esc | 打开 / 关闭鸟群菜单 |
| F、M | 返回主岛、切换音乐 |

菜单打开时鼠标释放，相机停止响应操作，鸟群、云、水、旗帜和音乐继续运行。滑杆实时调整；关闭菜单保留本次运行中的设置，恢复默认还原进入场景时的参数。不写入全局 PlayerPrefs。

## 鸟群调节

10 个滑杆：鸟群数量（16–128）、飞行速度、转向灵活度、感知半径、个体间距、分离 / 对齐 / 聚合权重、召集盘旋半径及停留时间。停留时间在正在进行的召集中也生效，缩短到已过去的时间会结束召集。

飞鸟模型池最多 128 个；第一次超过原始 64 只时扩充，其后复用模型和状态数组。未启用的飞鸟不渲染、不模拟。各小群的中心与方向按实际成员数计算，不依赖固定 16 只。避障始终保留。极端权重用于观察算法，不保证每种组合都维持默认的美术构图。

中文 UI 字体为 [Google Fonts 的 Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc) 的静态子集，重命名为 Sky City UI，附 SIL OFL 授权。`subset_font.py` 可从原始可变字体重建，只保留菜单使用的字符和 ASCII；新增中文文案后需重新生成字体。

## 世界与性能边界

- 保留空中花园的精细模型、烘焙间接光与材质，作为中央到达区；周围使用既有 WFC 模块生成可探索的浮岛城区。没有把低成本背景剪影作为真实城区。
- 主岛区域占用原点单元，流式生成跳过此单元和通向被省略单元的桥段。最多保留 25 个城区，2 个生成任务及 1 个上传阶段，远处卸载；近处才启用网格碰撞。
- `Physics.BakeMesh` 在工作任务中处理每个独立网格；完成后交换碰撞网格。卸载等待相关任务结束，避免读取已销毁网格。
- 第一人称相机使用 CharacterController。浮动原点与传送时暂时禁用碰撞体再移动，防止物理缓存把相机拉回旧坐标；主岛位置由原点坐标重新计算，避免大坐标往返损失精度。
- 主岛云密度 / 遮光缓存跨 280 m 单元重叠混合，维持连续体积云海。单份 32 MiB 缓存复用；反射使用同一云海与实时水面。
- 新场景独立于原固定构图样板，沿用 Unity 2022.3.62f2c1 / URP 14。周边模块与精细主岛仍存在美术质量差异，需要后续逐类重制。

## 重建、调试与实况

`SkyCityWorldBuilder.Build()` 从主岛样板创建世界；`BuildPlayer()` 构建 Windows 独立程序。修改现有场景通常不需要重新 Build 场景。

以 `-skyworld-review -skyworld-output "绝对路径.json"` 启动独立程序，可运行约一分钟的实际渲染验证，覆盖输入处理、碰撞、鸟群聚集 / 散开、跨区流式加载、浮动原点、百万坐标往返及确定性。性能测量时不截图；结果位于 `Captures/SkyCityWorld/Review.json`。公开输入处理函数测试与真实按键测试分开报告。

Unity MCP 可读写实际 Slider、回读群体参数、切换菜单、检查 Console，并用 `ScreenCapture.CaptureScreenshot` 截取包括菜单的 Game 画面，无需接管桌面鼠标。相机 RenderTexture 截图不包含 Screen Space Overlay 菜单。

Play 模式执行 `SkyCityWorldReview.Record()`，用 Unity Recorder 录制 30 秒 1920×1080 / 30 fps 的实际场景游览与菜单演示，包含音频。输出临时目录 `SkyCityWorld/FirstPersonJourney.mp4`。游览使用脚本相机路径，不冒充人工游玩，也不作为性能基准。

## 验证记录（2026-09-26）

Windows 独立程序，RTX 3090，1600×900，60 fps 上限，默认 64 只鸟：52.017 秒实际渲染 3120 帧，P95 16.671 ms、P99 16.786 ms，最大 17.582 ms；GPU P95 12.333 ms。鸟群与召集点平均距离从 37.93 m 降到 5.97 m。加载 128 个 / 卸载 104 个城区，峰值驻留 25 个、待处理 3 个任务，3 次浮动原点移动；百万坐标往返及主岛位置恢复通过，运行错误 0。构建错误与警告均为 0。

菜单另经 Unity MCP 检查全部 10 个滑杆的上下限、活动飞鸟实际数量（16 / 128）、模型池复用、默认值恢复、指针释放 / 锁定与相机姿态保持。真实 Esc 开关、拖动数量滑杆、恢复默认、菜单内 W / 右键输入隔离也完成检查。上述性能数据对应默认 64 只鸟，不代表所有极端参数组合。
