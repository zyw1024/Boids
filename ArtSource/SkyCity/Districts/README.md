# 天空之城街区与建筑模块

本目录为 `SkyCityWorld.unity` 的 WFC 街区提供制作源。入口为 `Assets/SkyCity/Scenes/SkyCityWorld.unity`，操作及运行边界见 [World 文档](../../../Sky_City_Project/Tools/World/README.md)。

## 128 个建模模块

16 个建筑家族，每家族 8 个结构变体。模块有不同的拱数、圆形或方形塔身、阶梯、分层塔楼、尖顶或穹顶、架空长廊、亭台和种植配置；旋转、镜像和换色不计入 128 个数量。`module-catalog.json` 保存每个模块的名称、连接掩码、三档三角形数量和几何 SHA-256。128 个最高细节模型具有 128 个不同的几何哈希。

家族包括：拱廊步道、转角游廊、市场柱廊、喷泉广场、悬空观景亭、穹顶圣所、钟楼、庭园回廊、梯田果园、宫廷图书馆、高架水道、转角天桥、仪式门楼、天文台、温室和冠冕宫殿。

- 可编辑 Blender 文件：`SkyCity_Modules.blend`。
- Unity 模块：`Assets/SkyCity/Content/Districts/Modules/` 中的 **128 个 Prefab**；每个含 LOD0 / LOD1 / LOD2 和连接标记。选中模块可看四向连接点。
- [模块总览](../../../Sky_City_Project/Captures/SkyCityInfinite_128Modules.png)：每列一个家族，每行一个变体，来自实际 Unity 网格渲染。
- 运行时使用 `Assets/SkyCity/Resources/SkyCityInfinite/Modules.bytes` 的压缩共享模型词汇，按需组合区块；不会实例化所有 Prefab。

## 构图与变化

建筑依附于连续悬崖和台地，不再每栋楼带一个重复的锥形小岛。模块之外另有八种城市构图：风之宫殿、狭长修道院、双岩体空中花园、阶台书库、孤峰天文塔、开放水庭、桥上村落、残缺柱廊遗迹。它们有不同的横纵比例、植被密度、建筑权重和海拔；相邻及对角相邻街区不会使用同一种地标。

宫殿和高塔是局部重音，低矮花园、水面和云谷形成留白。八种构图不计入 128 个模块数量。Blender 源文件同时保存模块目录和岛屿构图；`build_districts.py` 复用原天空之城的雕塑式建模函数，生成圆顶肋线、实体窗洞、拱廊、树冠、藤蔓与悬崖。LOD 降低采样和叶片数量，保留支撑柱，避免远景只剩悬空屋顶。

## 生成与加载

每个区块内有 8 × 8 个 12 米模块格，区块中心相隔 168 米；岛体按类型有不同横纵比例，建筑基面高度为 5–60 米。WFC 从最低 Shannon 熵的位置开始观察，按区域建筑权重坍塌，并传播四向连接、中心庭院和相邻高塔限制。连接桥在云谷中伸展，桥口的平面位置和高度由两侧共用的边界确定，因此加载顺序不影响接缝。同一种子和坐标会恢复相同布局。

求解最多重试 8 次。若所有尝试均矛盾，使用满足同一接口规则的确定性保底布局，并增加诊断计数；不会提交带矛盾的随机结果。当前规则测试包含多个种子、正负坐标和十亿级坐标，报告保留重试与保底次数。

运行时的边界：

- **默认最多 25 个驻留区块，可调为 9 / 25 / 49**，加载优先级略向视线前方偏移；外围保留迟滞，容量不足时先回收不再需要的最远区块。
- **最多 2 个后台任务**，执行 WFC 和网格拼装；另允许 1 个主线程待上传区块。任务完成前不访问 `Task.Result`。快速转移会取消过时任务、废弃过时结果。
- **主线程调度预算默认 2 ms / 帧**，将区块分为四个建筑网格、一个水面网格和一个透明瀑布网格上传。预算在操作之间检查；单次上传不是可抢占操作，因此预算不等于绝对无尖峰保证。
- 每个区块只上传当前距离需要的一档 LOD；采用迟滞切换，避免临界距离来回重建。相机之外的网格由 Unity 视锥剔除，远景不投影。
- 建筑按区块补丁合并，共享材质；燕群由当前世界的 `SkyCityFlock` 统一管理。近处启用区块碰撞壳。
- 最多复用 2 个空区块容器；卸载时释放其 Mesh，池中不积累旧地形。不会保存走过的所有区块或任务历史。
- 浮动原点在相机离局部原点约 384 米时平移。生成仍使用 `long` 街区坐标，云场保留周期坐标偏移。
- 云海、反射和鸟群使用唯一世界场景的共享系统，具体配置见 World 文档。

## 重建与验证

在仓库根目录运行：

```powershell
& '你的 Blender 路径/blender.exe' --background --factory-startup --python ArtSource/SkyCity/Districts/build_modules.py
```

Unity 完成导入后，选择 **Sky City → Assets → Bake 128 reusable prefabs** 更新编辑用预制体，然后在 `SkyCityWorld.unity` 中验证。`SkyCityModuleReview.ValidateAssets()` 检查预制体、LOD、透明瀑布、模型库和 Shader；**Sky City → Validation → Validate WFC constraints** 检查确定性与连接约束；`SkyCityStructureReview` 检查建筑连接。

制作脚本和压缩模型库是运行时几何的来源。只编辑预览 Prefab 不会自动修改模型库，需要同步制作源并重新导出。资源烘焙保留已有 GUID 和网格子资源标识。

[Gallery.md](Gallery.md) 保留街区制作阶段的实机画面；当前主岛、云、鸟群、碰撞和花园配置以唯一世界场景为准。最新验证见 [项目整理验证](../../../Sky_City_Project/Captures/SkyCityWorld/ProjectCleanup/README.md)。
